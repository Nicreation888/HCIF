2027 Community Solutions Grant Program

Competitive support for nonprofit programs that expand opportunity, improve well-being, and create sustainable local solutions.

Program overview

HCIF invites eligible nonprofit organizations serving communities in the United States to submit one proposal for a program aligned with a primary funding priority.
